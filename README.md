## Open Source Projects

Open source projects created in New Zealand or by Kiwi developers

## Startups

Innovative tech startups based in New Zealand

- [Xero](https://www.xero.com/) - Beautiful cloud-based accounting software.
- [Rocket Lab](https://www.rocketlabusa.com/) - Aerospace manufacturer and launch service provider.
- [Sharesies](https://www.sharesies.nz/) - Investment platform making investing accessible to everyone.
